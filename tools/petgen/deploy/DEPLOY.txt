aipet 定制宠物生成程序（petgen worker）
======================================

【运行时会访问的外网】只有：可灵 api-beijing.klingai.com、后台 aipei.pixpickai.com、阿里云 OSS。
【必须提前准备、不能让程序自己下载的】：

  1. 抠图模型（约 214 MB，程序默认从 GitHub 下载，国内下不了）
     开发机：tools/petgen/work/u2net/models/birefnet-general-lite/birefnet-general-lite.onnx
     放到：  本目录/u2net/models/birefnet-general-lite/birefnet-general-lite.onnx
     （md5 4fab47adc4ff364be1713e97b7e66334）

  2. Python 依赖（国内用镜像）
     export PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/
     pip install -r tools/petgen/requirements.txt

  3. ffmpeg / ffprobe：apt install -y ffmpeg

  4. 内存：抠图一步峰值约 6 GB。内存 + swap 合计至少 8 GB，否则进程会被系统杀掉（终端只显示 Killed）。
     加 8G swap：
       fallocate -l 8G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
       echo '/swapfile none swap sw 0 0' >> /etc/fstab

调试运行（解压到哪都行，下面以 ~/code/aipet 为例）：
  cd ~/code/aipet/secrets
  cp kling.env.example kling.env      # 填可灵 KLING_API_KEY、KLING_BASE_URL
  cp worker.env.example worker.env    # 填 AIPET_WORKER_KEY = PHP 后台 .env [AIPET] WORKER_KEY
  cd ~/code/aipet
  bash run.sh --once      # 只做一单就退出
  bash run.sh             # 一直领单，Ctrl+C 停止

  run.sh 启动前会检查密钥、模型、依赖、ffmpeg，缺什么会直接提示。

长期运行：tools/petgen/deploy/aipet-worker.service（路径按实际目录改），
或宝塔「进程守护」启动命令填：bash /你的目录/run.sh
